# public/data/ に置くファイル

このフォルダに置いたファイルは、アプリ起動時に自動で読み込まれます。

## 1. 3D可視化用データ

```
iiro_jis_264colors_plot_data.json
```

Python（UMAP）で出力した JSON。`/data/iiro_jis_264colors_plot_data.json`
として読み込まれ、「3D可視化」タブに表示されます。

## 2. バッチ生成タブの初期表示（前回の完成ファイル）

`src/App.tsx` の `DEFAULT_BATCH_URL` が指すファイル（現在は
`iiro_jis_264colors 2_結果.xlsx`）を起動時に読み込み、「説明」列を **生成済み**
として結果テーブルに初期表示します。改めて生成を実行したときだけ上書きされます。

別のファイル（新しい結果など）に切り替えたいときは `DEFAULT_BATCH_URL` を
その名前に変更してください（`.csv` でも可）。

※ いずれも文字化けを防ぐため **UTF-8** のまま（Python / アプリが出力した
元ファイルをそのまま）コピーしてください。
